# Фотографии жилых комплексов

Положите сюда файл с именем по коду ЖК из колонки GID исходной таблицы:

```
public/photos/U1.jpg        → ЖК Видинеевский (Уфа)
public/photos/KZN12.jpg     → соответствующий ЖК в Казани
public/photos/MSC3.webp     → ЖК в Московской области
```

Поддерживаются .jpg, .jpeg, .png, .webp, .avif. Регистр имени не важен.
После добавления файлов выполните `npm run build:data` — фото появятся
в списке ЖК и в попапах на карте.

Второй способ: заполнить колонку «Фото» в исходной Google-таблице
**прямой** ссылкой на картинку (адрес должен заканчиваться на .jpg/.png/.webp).
Ссылка на страницу фотохостинга (например ibb.co/xxxx) не подойдёт —
браузер не может показать её как изображение.

Список кодов ЖК: `node -e "require('./src/data/dataset.json').complexes.forEach(c=>console.log(c.gid, c.city, c.name))"`
